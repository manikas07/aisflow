# Data Quality Rules

Κανόνες καθαρισμού για το πέρασμα από bronze (raw CSV) σε silver (clean Parquet).
Κάθε κανόνας προέκυψε από παρατήρηση στα δεδομένα (AIS_2023_01_01).

## DQ-01: Heading sentinel value (511)

- **Στήλη:** `Heading`
- **Συνθήκη:** `Heading == 511`
- **Ενέργεια:** `Heading → null`. Η γραμμή **κρατιέται**.
- **Αιτία:** Το 511 δεν είναι πραγματική κατεύθυνση. Η πυξίδα πάει μόνο έως 360°.
  Είναι κωδικός που σημαίνει «μη διαθέσιμο». Εμφανίζεται κυρίως σε μικρά
  σκάφη χωρίς όργανο μέτρησης πλώρης. Στο `head` το είχαν 3 από τα 4 πλοία
  (μήκους 15–28 m), ενώ το πλοίο των 230 m είχε κανονική τιμή (97.0, κοντά στο COG 97.5).
- **Γιατί όχι drop:** Οι υπόλοιπες στήλες της γραμμής (θέση, ταχύτητα, χρόνος)
  είναι έγκυρες και χρειάζονται για τον υπολογισμό των voyages.
- **Αν μείνει ως έχει:** Θα αλλοίωνε στατιστικά (π.χ. μέσος όρος Heading).
